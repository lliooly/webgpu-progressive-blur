# 渐变模糊效果调试台

用户已确认把旧 demo 完全替换为效果调试台，不采用 landing page，不保留导航栏和介绍区块。

## 布局与交互

- 桌面左侧固定宽度控制栏独立滚动，右侧为实时效果画布；手机为画布与控制区上下排列。
- 圆形默认中心最模糊，向外围减弱；方形提供八个方向，箭头从模糊指向清晰。支持反转。
- 控件包括模糊强度、形状大小、渐变范围、叠加文字、形状轮廓、上传本地图片、恢复默认。
- 默认背景使用本地保存的山脉照片和大小文字、细线。文字也参与 WebGPU 模糊。
- 模糊区域支持指针拖动与键盘方向键移动；按住按钮或 Space / Enter 查看原图，松开恢复。

## 实现

保留 examples/navbar 的原有启动入口，重写 HTML、CSS、TypeScript，复用库的 reference mask 模式，不改动公开 API。Canvas 2D 绘制照片和文字源，再裁出模糊区域及 3-sigma 采样边界，交给 WebGPU 完成真实可变半径模糊。圆形使用径向 alpha mask；方形沿选定方向投影生成线性 alpha mask。形状尺寸由画布短边的百分比控制，渐变范围以中点对称展开。

使用 requestAnimationFrame 合并交互更新，静止时不持续重绘。图片和文字只在源内容或尺寸变化时重新绘制。WebGPU 不可用时保留原图并明确提示；本地图片解码失败时保留原背景。异步上传通过版本号避免覆盖较新的选择。

## 验证

类型检查、现有单元测试、库和 demo 构建，以及浏览器中的 WebGPU 像素变化、形状切换、八个方向、反转、滑块、拖动、键盘移动、按住原图对比、换图、恢复默认、移动端溢出和不支持 WebGPU 的状态。
